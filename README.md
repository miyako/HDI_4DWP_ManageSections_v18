# HDI_4DWP_ManageSections

**How Do I** (HDI) example: manage sections and subsections of a 4D Write Pro document by code.

Originally published for 4D v18 as a binary database, converted to a 4D project and modernised for 4D 21.

## Overview

| | |
|---|---|
| **Topic** | 4D Write Pro: sections, subsections, page layout |
| **Requires** | 4D 21 or later, valid 4D Write Pro license |
| **Blog post** | [Manage sections with code in a 4D Write Pro document](https://blog.4d.com/manage-sections-with-code-in-a-4d-write-pro-document/) |

## Getting started

1. Open `Project/HDI_4DWP_ManageSections.4DProject` with 4D 21 or later.
2. The `On Startup` database method runs `00_Start`, which opens the splash dialog.
3. Press **Demo** to open the demo window (also available from **File > Demo**, `Cmd/Ctrl+K`).

If the 4D version is too old or the 4D Write Pro license is missing, the splash dialog explains why and the button becomes **Close**.

## What the demo shows

The demo window has four tabs. Tab titles and descriptions are records of the `INFO` table, seeded from `Resources/INFO.4ie` on first run.

| Tab | Technique | Commands |
|-----|-----------|----------|
| Info | Overview of the section commands | |
| Sections | List sections, select one, set columns and page margins | `WP Get sections`, `WP SET ATTRIBUTES` (`wk column count`, `pageMargin`), `WP SELECT` |
| Subsections | Create left/right subsections, set a different background on each | `WP Get section`, `WP New subsection`, `WP Get subsection`, `WP SET ATTRIBUTES` (`wk background color`) |
| Reference | Additional notes | |

The sample documents are generated by `createDoc1` (three sections) and `createDoc2` (one section) using `WP New`, `WP SET TEXT` and `WP Insert break` (`wk section break`).

## Points of interest

- **Section references in a collection list box.** `WP Get sections` returns a collection of section objects (`sectionIndex`, `start`, `end`) that is bound directly to a collection list box. Selecting a row calls `WP SELECT` to move the cursor into that section.
- **Left/right subsections.** `WP New subsection` on the first section with `wk left page` creates both the left and right subsection. Each can be styled independently.
- **Non-blocking startup.** `00_Start` uses `CALL WORKER` and `DIALOG(...; *)` instead of `New process` and a blocking `DIALOG`. A second invocation brings the existing window to front instead of opening a duplicate.
- **Reusable splash form.** The `HDI` form is driven entirely by the `Form` object (`title`, `info`, `blog`, `minimumVersion`, `license`) and is shared across HDI examples.
- **Dark mode and Liquid Glass.** Colours use `automatic` / `automaticAlternate` or CSS classes with `prefers-color-scheme` media queries (`styleSheets.css`). Button heights are set per platform theme (27px `liquid-glass`, 23px `mac-classic`) in `styleSheets_mac.css` and `styleSheets_windows.css`.
- **XLIFF localisation.** All UI text uses `:xliff:` references or `Localized string`. English and Japanese are provided in `Resources/en.lproj` and `Resources/ja.lproj`.
- **Standard menu actions.** Quit, Edit and Mode menu items use 4D standard actions rather than wrapper methods.

## Project layout

```
Project/Sources/
  DatabaseMethods/onStartup.4dm   starts 00_Start
  Methods/00_Start.4dm            splash/startup launcher
  Methods/createDoc1.4dm          sample document, 3 sections
  Methods/createDoc2.4dm          sample document, 1 section
  Forms/HDI/                      splash dialog
  Forms/HDI2/                     demo window (tabs, list box, Write Pro areas)

  styleSheets*.css                colour scheme and theme rules
Resources/
  en.lproj, ja.lproj              XLIFF files
  INFO.4ie, INFO.4si              seed data for the INFO table
```
